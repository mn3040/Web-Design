# Bronx Bombers Media -- Web Design Final

## Overview

Bronx Bombers Media is a responsive, multi-page sports media platform
built to deliver Yankees analysis, player spotlights, and interactive
fan engagement content. The project emphasizes structured semantic
design, performance optimization, and accessible front-end architecture.

## Features

-   Responsive multi-page layout (Home, Analysis, About/Contact)
-   Dynamic Player Spotlight section using JavaScript DOM manipulation
-   Interactive Hot Take comment toggle functionality
-   Mobile-first navigation with accessible ARIA labeling
-   Optimized responsive images using srcset for multi-resolution
    support
-   Secure external linking using rel="noopener noreferrer"

## Tech Stack

-   HTML5
-   CSS3 (Flexbox & Grid)
-   JavaScript (Vanilla JS, event handling, DOM manipulation)

## Engineering Focus

-   Semantic HTML5 structure for accessibility
-   Deferred JavaScript loading for improved rendering performance
-   Clean UI component modularization
-   Client-side security best practices for external links

## Key Takeaways

-   Built scalable front-end architecture without external frameworks
-   Strengthened responsive design and performance optimization skills
-   Applied accessibility and security-conscious design principles
