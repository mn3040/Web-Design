# Bronx Bombers Media

## 📋 Overview

Bronx Bombers Media is a responsive, multi-page sports media platform dedicated to New York Yankees content. Built from scratch with semantic HTML5, modern CSS3, and vanilla JavaScript, this project delivers Yankees analysis, player spotlights, and interactive fan engagement features while prioritizing performance, accessibility, and security.

## ✨ Features

- **Responsive Multi-Page Design** — Home, Analysis, and About pages optimized for desktop, tablet, and mobile
- **Dynamic Player Spotlight** — JavaScript-driven DOM manipulation for interactive player content
- **Interactive Hot Takes** — Collapsible comment sections with smooth toggle functionality
- **Accessible Navigation** — Mobile-first navigation with semantic HTML5 and ARIA labeling
- **Optimized Images** — Responsive images with `srcset` for multi-resolution support
- **Security Best Practices** — External links protected with `rel="noopener noreferrer"`
